## 今日の注目

🔥 **TkDodo が TanStack Query の Suspense 連携を `React.use` へ移行**しています。[Promise を throw する方式から `React.use` へ切り替える PR](https://github.com/TanStack/query/pull/10366) が、この日の注目です。React Suspense の初期に用いられた Promise を throw する回避策を、公式の `React.use` API に置き換えます。React 周辺のライブラリも、初期の Suspense の実装方法から安定版 API への移行を進めています。TanStack Query の Suspense モードを使う全ユーザーに影響する変更です。

**iOS Safari で ViewTransition がクラッシュする問題** ([#35336](https://github.com/facebook/react/issues/35336)) に、Dan Abramov と Sebastian Markbåge の両氏が関心を寄せました。React の新しい View Transitions 機能を広く使う前に、解消が必要な互換性の問題です。
