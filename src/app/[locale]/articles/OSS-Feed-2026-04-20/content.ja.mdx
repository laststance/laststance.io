React、TanStack、JavaScript 周辺で過去 24 時間にあった OSS 活動をまとめました。

Tanner は TanStack 周辺の改善に取り組みました。

**作成した PR**

- **[パフォーマンス改善のため React を @tanstack/dom-vite に置き換える](https://github.com/TanStack/tanstack.com/pull/836)**。TanStack のウェブサイトで React を軽量な DOM シムに置き換え、高速化を図ります。

### [@TkDodo](https://github.com/TkDodo) - Dominik

Dominik は TanStack Query と Sentry の両方で多数の変更に関わりました。

**TanStack Query へのコントリビューション**

- **[vue-query に mutationOptions を追加する](https://github.com/TanStack/query/pull/10036)**。Vue Query でミューテーションオプションを使えるようにします。

**Sentry へのコントリビューション**

- UI を改善し、テストを安定させました。通知キャッシュの無効化、進捗が未確定のときのローダー追加、タイムゾーンのツールチップ修正、バージョンを表示するホバーカードの改善、ステータス表示の重なり順、Seer の SCM 改善、フックのリファクタリング、スパンの根拠情報を表示するプレビューの修正、スロットコンポーネントの追加などです。

### [@kettanaito](https://github.com/kettanaito) - Artem Zakharchenko

Artem は MSW Data の改善に集中し、7 件の PR を出しました。

**MSW Data の改善**

- **[`rettime` を更新する](https://github.com/mswjs/data/pull/360)**。依存関係の rettime を更新しました。
- **[リスナーリークと `.earlyOn` のリスナーが再び値を返す問題を修正する](https://github.com/kettanaito/rettime/pull/37)**。rettime の重大なメモリリークを修正しました。
- **[依存関係を更新する](https://github.com/mswjs/data/pull/359)**。定期的な依存関係のメンテナンスです。
- **[配列への push でリレーションを更新できるようにする](https://github.com/mswjs/data/pull/358)**。関連データの取り扱いを改善しました。
- **[配列の再代入で一対多のリレーションを更新できるようにする](https://github.com/mswjs/data/pull/357)**。一対多の関連の取り扱いを改善しました。
- **[関連のリスナーを解除してリークを防ぐ](https://github.com/mswjs/data/pull/356)**。メモリリークを予防します。
- **[一意なリレーションの更新を正しく検査する](https://github.com/mswjs/data/pull/355)**。一意制約の検査を改善しました。
