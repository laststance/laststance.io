デモには3色のボックスがあります。

- **赤いボックス**（fixed）は、スクロールしても画面の右上にとどまります。
- 左側の**青緑のボックス**（sticky）は、最初は普通に流れ、スクロールが一定の位置まで進むと上端に張り付きます。
- **灰色のボックス**では、通常のスクロールと比較できます。

各ボックスの中とページ全体の両方をスクロールして、動きの違いを見てください。

## position: fixed 📌

- **画面上の同じ位置に固定されます。** 基準はビューポート（ブラウザーの表示領域）なので、いくらスクロールしても動きません。
- **通常のレイアウトの流れから外れます。** 周囲の要素は、そこにボックスがないものとして配置されます。
- ビューポート内の座標に置けば**常に表示**されます。
- フローティングアクションボタン、チャットウィジェット、常に表示するナビゲーションバーなどに使います。

## position: sticky 🍯

- **途中で動きが変わります。** 初めは普通の要素と同じように流れ、指定した位置まで来ると張り付きます。
- **レイアウト上の場所を確保します。** 他の要素の配置には通常通り影響します。
- **固定される範囲は親コンテナの中です。** 親が画面外に流れると要素も一緒に移動します。
- テーブルのヘッダー、セクションの見出し、スクロールに追従するサイドバーなどに使います。

## 動きの早見表

```
FIXED:     常にビューポート内の同じ位置
           ┌─────────────┐
           │   Fixed     │ ← スクロールしても動かない
           └─────────────┘

STICKY:    通常の配置 → 指定位置で固定 → 親と一緒に移動
           ┌─────────────┐
           │   Sticky    │ ← 指定位置までは流れ、
           └─────────────┘   その位置で固定される
```
