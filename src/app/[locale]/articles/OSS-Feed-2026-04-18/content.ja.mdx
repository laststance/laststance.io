## 今日の注目

今日は次の 2 つの動きが目を引きました。

1. **MSW が `navigate` リクエストのインターセプトに対応へ。** Artem ([@kettanaito](https://github.com/kettanaito)) は [msw#2721](https://github.com/mswjs/msw/pull/2721) をドラフトとして作成しました。数年来の機能要望 [Issue #1594](https://github.com/mswjs/msw/issues/1594) の実装です。テストやローカル開発で MSW を使って API をモックする人に関係する変更です。

2. **Andrew Clark が Next.js のプリフェッチの仕組みを見直しています。** 関連する 3 件の PR ([#92908](https://github.com/vercel/next.js/pull/92908)、[#92761](https://github.com/vercel/next.js/pull/92761)、[#92859](https://github.com/vercel/next.js/pull/92859)) が進みました。プリフェッチのインライン化と `instant` の設定に関わるため、今後のリリースでは App Router のページ遷移の挙動も変わりそうです。

[@TkDodo](https://github.com/TkDodo) は `getsentry/sentry` に 1 日で **7 件**の PR を出しました。アプリ全体で `apiOptions` へ少しずつ移行する、大規模なリファクタリングの一例です。
