[vite-rtk-query](https://github.com/laststance/vite-rtk-query) を更新しました。

### React Router v6 の設定

[React Router](https://reactrouter.com/en/main) と [redux-first-history](https://github.com/salvoravida/redux-first-history) を追加しました。\
redux-first-history を使うと、Redux のアクションをディスパッチして React Router のページを遷移できます。

### CSS Modules のネスト

CSS Modules でスタイルを書きやすくするため、[postcss-nesting](https://www.npmjs.com/package/postcss-nesting) を追加しました。
Redux のピア依存関係でエラーになる場合は、`npm i --force` を使ってインストールしてください。
