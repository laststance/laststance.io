## TypeScript 6.0 Beta のリリース告知

- 公開日 2026-02-11.
- **概要**。TypeScript 6.0 Beta は、5.9 から TypeScript 7.0 のネイティブ実装（Go）への移行を見据えたリリースです。**現行の JavaScript コードベースを使う最後のメジャーバージョン**となる予定です。注目すべき新機能がいくつかあり、設定の変更や非推奨化も広範囲に及びます。
  - **最大のテーマは TypeScript 7.0 への準備**。TS 6.0 では動作と既定値を揃え、`--stableTypeOrdering` などの移行支援も用意することで、ネイティブの TS 7.0 ツールチェーンへ移行するときの想定外の差を減らします。
  - **主な変更点**
    - **`this` を使わないメソッドの型推論を改善**。関数内で `this` を使わない場合、文脈への依存度が低いと見なされます。これにより、メソッド構文を使ったオブジェクトリテラルの型推論が改善します。
    - **Node.js と package.json まわりの改善**。`#/` で始まるサブパスインポートに対応し、`--moduleResolution bundler` と `--module commonjs` を組み合わせやすくなりました。
    - **ライブラリの型定義とターゲットを更新**。`target` と `lib` に `es2025` を指定できます。`Temporal` と、Map / WeakMap の新しい「なければ挿入する」メソッド（`getOrInsert*`）、`RegExp.escape` の組み込み型定義も追加されました。
    - **DOM ライブラリの整理**。`lib.dom.iterable.d.ts` と `lib.dom.asynciterable.d.ts` にあった型定義は、すべて `lib.dom.d.ts` に含まれるようになりました。
    - **破壊的変更と既定値の変更**。`strict` の既定値は `true` に、`module` は `esnext` に、`target` は当年分の ECMAScript（現在は `es2025`）になります。非推奨化や削除も多数あります。

  - **目次の要約**
    - **`this` を使わない関数の文脈依存を軽減**。`this` を使わないメソッド構文の型推論を改善します。
    - **`#/` で始まるサブパスインポート**。新しいモジュール解決方式では、Node.js の `#/` 形式のサブパスインポートが使えます。
    - **`--moduleResolution bundler` と `--module commonjs` の併用**。古い Node.js 向けのモジュール解決方式を使っているプロジェクトに、現実的な移行先ができました。
    - **`--stableTypeOrdering` フラグ**。TS 6 と TS 7 で出力や型の並び順の差分を減らします。型チェックが目に見えて遅くなる場合があります。
    - **`target` と `lib` に `es2025` を追加**。主に、組み込み API の型定義が増えます。
    - **`Temporal` の型定義を追加**。日付と時刻を扱う Temporal API の組み込み型定義が `esnext`（または `temporal.esnext`）に加わります。
    - **「なければ挿入する」メソッド（`getOrInsert*`）の型定義を追加**。Map / WeakMap の新しい取得・挿入 API の型定義が `esnext` に加わります。
    - **`RegExp.escape`**。`es2025` に新しい標準メソッド `RegExp.escape` の型定義が加わります。
    - **`dom` が `dom.iterable` と `dom.asynciterable` を含む**。DOM の反復・非同期反復の型宣言を `dom` にまとめます。
    - **TypeScript 6.0 の破壊的変更と非推奨化**。今日の JavaScript エコシステムに合わせて設定を広く整理し、TS 7.0 への移行に備えます。
      - **最初に見直す項目**。アップグレード後に多くのプロジェクトで必要となる修正です（`types`、`rootDir` など）。
      - **既定値の変更**。`strict: true` や `module: esnext` が新しい既定値になり、`target` の既定値は更新されていきます（現在は `es2025`）。
      - **`target: es5` の非推奨化**。ES5 への出力は非推奨となり、指定できる最も古いターゲットは ES2015 になりました。
      - **`--downlevelIteration` の非推奨化**。ES5 向けの出力に結び付いているため非推奨になります。
      - **`--moduleResolution node`（node10）の非推奨化**。`nodenext` または `bundler` へ移行します。
      - **モジュールの出力形式 `amd`、`umd`、`systemjs` の非推奨化**。これらの形式はサポート対象外になります。
      - **`--baseUrl` の非推奨化**。意図しない場所からモジュールを検索する事態を避けるため、明示的に `paths` を指定します。
      - **`--moduleResolution classic` の非推奨化**。削除されるため、現在主流の解決方式へ移行します。
      - **`--esModuleInterop false` と `--allowSyntheticDefaultImports false` の非推奨化**。モジュール間の相互運用で、より安全な挙動が常に有効になります。
      - **`--alwaysStrict false` の非推奨化**。TypeScript は strict モードを前提とします。非 strict モードの挙動を前提としたコードは調整が必要になる場合があります。
      - **`outFile` の非推奨化**。この設定は削除され、代わりにバンドラーを使います。
      - **名前空間の旧 `module` 構文の非推奨化**。`module Foo {}` は明示的に非推奨となります。`namespace` を使います。
      - **インポート時の `asserts` キーワードの非推奨化**。`with` を使うインポート属性に置き換わります。
      - **`no-default-lib` ディレクティブの非推奨化**。`/// <reference no-default-lib="true"/>` はサポート対象外になります。
      - **`tsconfig.json` がある状態で CLI にファイルを指定するとエラーになる**。設定を無視して実行する場合は `--ignoreConfig` を明示します。

    - **TypeScript 7.0 への準備**。TS 7 へ円滑に移行できるよう、今のうちに非推奨項目へ対処する方法を案内しています。
    - **今後の予定**。ベータの時点で機能は固まっています。正式リリースまでは不具合修正とフィードバックへの対応が中心です。

- 告知記事 [Announcing TypeScript 6.0 Beta](https://devblogs.microsoft.com/typescript/announcing-typescript-6-0-beta/)

## TypeScript 5.8 のリリース告知

- 公開日 2025-02-28
- **概要**。次のような機能追加と改善があります。
  - **return 式の分岐を個別にチェック**。return 文の条件式をより細かく型チェックし、見つけにくい不具合を検出します。
  - **`require()` で ECMAScript モジュールを読み込める**。Node.js 22 との互換性のため、`--module nodenext` を指定すると CommonJS モジュールから ESM を読み込めます。
  - **新しい `--module node18` フラグ**。Node.js 18 を使い続ける場合に、`--module nodenext` の一部の新しい挙動を取り込まず、安定した基準にできます。
  - **`--erasableSyntaxOnly` オプション**。TypeScript 固有の構文をそのまま取り除けるものに制限し、Node.js 23.6 の実験的な TypeScript 対応との互換性を高めます。
  - **`--libReplacement` フラグ**。コンパイル時にライブラリの定義ファイルを置き換える挙動を細かく制御できます。
  - **計算されたプロパティ名を保持**。宣言ファイルでの計算されたプロパティ名の扱いが改善され、出力を予測しやすくなります。
  - **パフォーマンス改善**。プログラムの読み込みと更新が速くなり、とくに大規模プロジェクトでビルドやエディターの応答性が向上します。
- 告知記事 [Announcing TypeScript 5.8](https://devblogs.microsoft.com/typescript/announcing-typescript-5-8/)

## TypeScript 5.7 のリリース告知

- 公開日 2024-11-22
- **概要**。次のような改善が加わりました。
- **初期化されていない変数の検出**。代入前に使った変数をエラーとして報告します。ネストした関数から参照した場合も検出できます。
- **相対パスの書き換え**。新しいコンパイラーオプション `--rewriteRelativeImportExtensions` を使うと、TypeScript の拡張子で終わる相対インポートパスを、コンパイル時に対応する JavaScript の拡張子に書き換えます。
- **`--target es2024` と `--lib es2024` に対応**。ECMAScript 2024 をターゲットにでき、`Object.groupBy`、`Map.groupBy`、`Promise.withResolvers` などの機能を使えます。
- **所属プロジェクトを特定するために親ディレクトリの設定を探索**。言語サービスがディレクトリをさかのぼって `tsconfig.json` を探し続けるようになり、プロジェクト構成の自由度が上がりました。
- 告知記事 [Announcing TypeScript 5.7](https://devblogs.microsoft.com/typescript/announcing-typescript-5-7/)
