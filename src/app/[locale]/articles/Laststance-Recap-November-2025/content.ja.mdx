11月の Laststance では、18のプロジェクトで350コミット、20件の PR のマージ、8件のリリースがありました。新たに3つのプロジェクトを公開し、既存アプリにはテーマ機能を実装しました。フレームワークの移行も進んだ1か月を振り返ります。

## <a href="https://laststance.github.io/complete/" target="_blank" rel="noopener noreferrer" className="no-underline text-inherit hover:text-inherit">complete</a>

Swift で作った、macOS のアプリを横断して使える入力補完ツールです。

**今月の変更**

- [macOS 全体で使える入力補完アプリ v1.0.0 を公開](https://github.com/laststance/complete/commit/7f39c49ef3853cc23d11256dd77c1165b75e1354)
  - キーボードで候補を選択でき、フォーカスも自動で管理する macOS ネイティブツールの初回リリースです。

- [アプリ全体に依存性注入を導入](https://github.com/laststance/complete/commit/5b14006af05c696a96ea90c17903a6f8aba20522)
  - すべてのコンポーネントで依存関係を外から渡せるようにし、テストとメンテナンスをしやすくしました。

- [AccessibilityManager を役割ごとの5つのクラスに分割](https://github.com/laststance/complete/commit/4d7d76f2a399a1abe8b9fe15a6cbe94904a644d6)
  - 機能が集中していた巨大なクラスを分割し、それぞれが1つの責任を持つよう整理しました。

---

## <a href="https://coffee-timer-laststance.vercel.app/en" target="_blank" rel="noopener noreferrer" className="no-underline text-inherit hover:text-inherit">coffee-timer</a>

豊富なテーマとアクセシビリティ機能を備えた PWA のタイマーです。

**今月の変更**

- [Apple の Liquid Glass を取り入れたテーマを実装](https://github.com/laststance/coffee-timer/commit/cafec490d796b825b50c74b19af4d283f32c8d7f)
  - ガラスの質感を生かしたデザインを7種類のバリエーションから選べるようにしました。

- [高コントラストモードの文字色を OKLCH で算出](https://github.com/laststance/coffee-timer/pull/18)
  - 人間の知覚に近い色空間を使い、どのテーマでも文字を読みやすくしました。

- [見た目の変化を検出する回帰テストを追加](https://github.com/laststance/coffee-timer/commit/3aef79ebcb14f0297605b429b7ab6b8c79ff18f6)
  - Playwright によるビジュアルテストで、意図しない表示の変化を検出できるようにしました。

---

## <a href="https://github.com/laststance/corelive" target="_blank" rel="noopener noreferrer" className="no-underline text-inherit hover:text-inherit">corelive</a>

Electron で作った、個人用のタスク管理・ナビゲーションアプリです。

**今月の変更**

- [100種類以上のテーマに対応する CoreLive のデザインシステムを実装](https://github.com/laststance/corelive/commit/1ebbe64f5b5cb794b16677a2bae0227e6d2e4c35)
  - テーマの基盤を整備し、利用者が幅広い選択肢から好みの表示を選べるようにしました。

- [データベースアダプターを導入し、Prisma を v6 から v7 に移行](https://github.com/laststance/corelive/commit/dceaff4c419fa73cf3f1dae43816e45f8dccd499)
  - ESM に対応し、データベースの扱いも改善しました。

- [IPC で FloatingNavigator とメインウィンドウのタスクを同期](https://github.com/laststance/corelive/pull/9)
  - どちらのウィンドウで操作しても、タスクの変更をもう一方に反映します。

## 11月を振り返って

11月は complete、react-next-eslint-plugin、create-web-site の3つが生まれました。coffee-timer の Liquid Glass や corelive の100種類以上のテーマなど、使う人が自分の好みに合わせて見た目を変えられるようになった月でもあります。
react-next-eslint-plugin の JSDoc に貢献してくれた @shanaya-Gupta をはじめ、協力してくださった皆さんに感謝します。今月は8件をリリースできました。これからも Web とデスクトップの両方で開発を続けていきます。
