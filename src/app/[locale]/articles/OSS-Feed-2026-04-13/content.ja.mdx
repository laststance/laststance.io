# OSS Feed（2026年4月13日）

React と JavaScript 周辺で活躍するエンジニアの過去 24 時間の OSS 活動をまとめました。

## [@tannerlinsley](https://github.com/tannerlinsley)

Tanner は TanStack のプロジェクトで、React Server Components とブラウザ互換性に取り組みました。

- **マージ**。[React Server Components の記事の焦点を絞る](https://github.com/TanStack/tanstack.com/pull/821)。TanStack の RSC ドキュメントを更新しました。
- **マージ**。[start-rsc がブラウザの Promise.withResolvers に依存しないようにする](https://github.com/TanStack/router/pull/7162)。Promise.withResolvers への依存を外し、ブラウザ互換性の問題を修正しました。

## [@timneutkens](https://github.com/timneutkens)

Tim は Next.js の開発で活発に活動し、特にパフォーマンスと Node.js ストリームに取り組みました。

- **PR を作成**。[OpenTelemetry が無効なときに trace() の高速パスを使う](https://github.com/vercel/next.js/pull/92678)。OpenTelemetry のトレース処理を最適化します。
- **複数の PR をレビュー**。エラー復旧時の分岐点、レンダリング処理、ストリームの扱いなど、Node.js ストリームの実装に関わりました。

## [@bvaughn](https://github.com/bvaughn)

Brian は react-resizable-panels を改善しました。

- **マージ**。[data-separator に「focus」状態を追加する](https://github.com/bvaughn/react-resizable-panels/pull/706)。区切り要素にフォーカス状態を示すデータ属性を追加し、アクセシビリティを改善しました。

## [@sebmarkbage](https://github.com/sebmarkbage)

Sebastian は React 周辺の議論に参加しました。

- [React Server Components への対応](https://github.com/testing-library/react-testing-library/issues/1209) にコメントしました。Testing Library での RSC 対応を議論しています。
- [新しい select パーサーに合わせて HTML パーサーのルールを更新する](https://github.com/facebook/react/pull/34804) をレビューしました。React 本体の HTML 解析を改善します。

## [@TkDodo](https://github.com/TkDodo)

Dominik は Sentry の開発に参加しました。

- [プロジェクトアラートの設定フォームを AutoSaveField に移行する](https://github.com/getsentry/sentry/pull/109367) にコメントしました。Sentry のアラート設定 UI の改善です。

## [@phryneas](https://github.com/phryneas)

Lenz は Redux Toolkit と Apollo Client で活動しました。

- Redux Toolkit では、ミドルウェアの登録やクエリの拡張など複数の Issue で議論しました。
- Apollo Client では非推奨の警告の抑制とエラー処理に取り組みました。

## [@markerikson](https://github.com/markerikson)

Mark は Reselect のメンテナンスに力を入れました。

- パフォーマンスの最適化、キャッシュの改善、メモリリークの調査、メモ化の挙動について広く Issue を確認し、議論しました。
- React Redux のバンドルサイズを最適化する変更をレビューしました。

## [@kettanaito](https://github.com/kettanaito)

Artem は React Server Components の新しいテスト用プラグインを開発しました。

- **Issue を作成**。[サーバー側のテストセットアップ](https://github.com/kettanaito/vite-plugin-rsc-testing/issues/11)。サーバー側のテスト基盤を計画しています。
- **Issue を作成**。[名前付きインポートの検査で型のインポートを無視する](https://github.com/kettanaito/vite-plugin-rsc-testing/issues/10)。TypeScript 対応の改善です。
- **マージ**。[モジュールを分離して評価する処理を実装する](https://github.com/kettanaito/vite-plugin-rsc-testing/pull/9)。テストを分離して実行するための中核機能です。
- MSW（Mock Service Worker）周辺の議論にも参加しました。

## 今日の注目

**Kettanaito の RSC テストへの取り組み**。Artem は `vite-plugin-rsc-testing` の開発を進めています。モジュールを分離して評価する仕組みとサーバー側のテスト基盤は、RSC でいま不足しているテスト手段を補います。RSC の採用が広がれば、コミュニティ全体に役立ちそうです。

Tim は Next.js で Node.js ストリームを最適化しています。引き続き進む基盤部分の高速化は、あらゆる Next.js アプリに恩恵があります。
