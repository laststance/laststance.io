React と Next.js 周辺では、金曜日も活発な動きがありました。Andrew Clark は React の修正をマージし、Next.js でオフライン対応のフックを試しました。Tanner Linsley は TanStack DB の大きな RFC を公開し、Theo は t3code の開発を進めました。

## [@acdlite](https://github.com/acdlite)

Andrew は React 本体の修正をマージし、Next.js で実験的なドラフト PR を 2 件作成しました。

- **Suspense のフォールバックへのコンテキストの伝播を修正**。 [facebook/react#36160](https://github.com/facebook/react/pull/36160)。Suspense のフォールバック境界までコンテキスト値が正しく届かないバグを直しました。
- **［実験］アプリコードからオフライン状態を取得できる useOffline フックを追加**。 [vercel/next.js#92012](https://github.com/vercel/next.js/pull/92012)（ドラフト）。コンポーネントがオフラインとオンラインの切り替わりに反応できる新しいフックです。
- **［実験］オフライン時の再試行を制御する useOffline フラグを追加**。 [vercel/next.js#92011](https://github.com/vercel/next.js/pull/92011)（ドラフト）。接続が復旧したときに自動で再試行する、上記と対になる PR です。

## 今日の注目

今日は **Tanner Linsley の TanStack DB RFC** に注目です。テストしやすくする依存性注入、API をシンプルにするステートレスなコレクション記述子、フレームワークとの互換性を保つ SSR のハイドレーションを一緒に扱っています。TanStack の動向を追っているなら、目を通して議論に参加したい RFC です。 [TanStack/db#1420](https://github.com/TanStack/db/issues/1420)

**acdlite の Next.js での `useOffline` の実験**も気になります。フレームワーク自体にオフライン対応が入る可能性があり、Next.js で PWA を開発する人には大きな変化です。
