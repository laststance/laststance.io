CSS の fr が何を表すのか、ずっと曖昧なままでした。Grid や Flexbox の入門記事をいくつ読んでも、「割合を表す単位」という説明だけでは、実際の幅をうまく想像できなかったのです。

腑に落ちたのは、[W3C の仕様書](https://drafts.csswg.org/css-grid/#fr-unit) にある次の一文を読んだときでした。

> 7.2.4 柔軟な長さと fr 単位（筆者訳）
>
> 柔軟な長さ（`<flex>`）とは、グリッドコンテナ内で余ったスペースの取り分を表す、fr 単位の寸法のことです。

ポイントは「余ったスペース」です。コンテナ全体にいきなり割合を掛けるわけではありません。固定幅の列や内容に合わせて幅が決まる列が必要な分を取った後で、残りを分け合います。

1. fr を使わないトラック（px、auto、minmax など）のサイズを計算する。
2. 残っているスペースを求める。
3. 残りを、1fr、2fr などで指定した係数に応じて分配する。

こう考えると、入門記事では説明を省きがちな挙動も理解できます。

- 余りがなければ、1fr の計算結果が 0 になることがある。
- .5fr、1fr、2fr は、それぞれの係数に応じて余りを分け合う。
- コンテナで利用できるサイズが不定だと、fr で指定したトラックが内容に合わせたサイズになることがある。

Flex や Grid の入門記事には、最初の一歩を助けてくれる良いものがたくさんあります。でも今回は、仕様書を読む方が近道でした。少し技術的でも、そこには用語そのものの定義があり、たった一行で全体の見え方が変わることがあります。

fr の動きに迷ったら、まず仕様を読んでから、チュートリアルのパターンや例を見直してみてください。私には、その方が速く、正確に理解できました。
